Keep Focus uses Android AccessibilityService as a core focus-reminder feature. After the user completes a separate in-app disclosure and affirmatively agrees, the service listens only to accessibility scroll and window-state events from the explicitly selected packages com.instagram.android and com.google.android.youtube. The service uses package identity and event type/timing to estimate continuous short-video scrolling and trigger a reminder based on a user-selected threshold. It does not inspect or store screen text, messages, passwords, typed input, video content, or content descriptions. No accessibility event data is transmitted off-device, sold, or shared. The user can disable the service at any time in Android Settings. Keep Focus is not an accessibility tool and does not declare isAccessibilityTool=true.
